Developed an interactive orbital traffic-awareness platform that visualizes satellite trajectories and explores potential close-approach scenarios. Integrated simulated future states, alternate orbital trajectories and telemetry, along with an AI mission advisor to analyze scenarios and provide decision-support insights. The project focuses on understanding how orbital decisions can affect the surrounding space environment.
A 3D model of the Earth which displays space debris in real time using sources like- CELESTRAK and NORAD GP.
Includes features to view debris in zones such as- LEO, NEO, GEO.
Has a view to see the change in amount of space debris and predict the amount which can be changed using a slidebar.
Has a Collision avoidance system and a simulation to view renewed flight paths along with other data
